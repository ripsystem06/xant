# Xant — Desarrollo e Ingeniería

Sitio web de **Xant**, empresa de soporte técnico empresarial y soluciones tecnológicas con sede en Ensenada, Baja California.

## Servicios

- Soporte técnico empresarial
- Desarrollo web
- Automatización de procesos
- Diagnóstico gratuito y soporte continuo

## Tecnología

Sitio estático construido con HTML, CSS, JavaScript y Tailwind CSS.
